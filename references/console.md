# 网页租机与 SSH

Windows 本机环境与点击错位排查见 [windows.md](windows.md)。

## 已观察到的网页流程（2026-09-07）

市场 <https://matgo.cn/host-market/gpu> 未登录可查看 GPU、区域、单份显存、CPU、内存、硬盘、驱动、可用份数和计费选项。初次载入可能暂时没有卡片，待页面数据完成后再判断。

页面顺序：选择算力 → 计费方式 → 选择镜像 → 高级配置 → 订单汇总。“高级配置”显示自定义端口、环境变量、入口命令。点击“选择镜像”在未登录时跳转登录页；登录后的菜单需实时确认。不要点击下单来探测接口。

同一型号可有多条区域或驱动不同的配置。多卡显存不是单个 GPU 的连续显存，任务必须支持分布式或切分。按时/包日/包周/包月比较以最终金额为准。网盘扩容和自动续费不能默默加入订单。

## 镜像、持久化与连接

官方教程：<https://matgo.cn/supports/doc-quick-start/>

- 镜像需匹配项目 Python、框架、CUDA 和 GPU 架构。不要照搬旧教程的 K80、PyTorch 1.10 等示例。
- SSH 公钥、VNC 和自定义端口需在创建前检查；教程说明相关配置启动后不能直接修改。优先使用已授权公钥，只上传公钥，不上传私钥。
- 运行后从租用列表“常用信息”获取 SSH/JupyterLab/VNC 信息。不要推测主机、端口、用户名或密码。

官方 FAQ：<https://matgo.cn/supports/reference/faqs/>

- 网盘通常挂载 `/mnt`，可自定义；不同区域网盘不互通。实例释放不删除持久网盘文件，但扩容到期/欠费规则须核实现行说明。
- 按时租用在运行状态计费；关闭终端或结束训练不等于结束网页实例租赁，完成后检查平台释放状态。
- 保存环境占用网盘空间；不要将其视为已验证的完整数据备份。

## 已有实例运行任务

连接后核实 `hostname`、`nvidia-smi`、项目解释器及 `df -h`、`findmnt` 的实际挂载；`findmnt` 不可用时用 `mount`/平台配置交叉确认。与本地终端区分清楚。

使用实际参数调用 `ssh -p PORT USER@HOST`；SCP 端口为 `-P`，rsync 通过 `-e 'ssh -p PORT'`。保留 SSH 主机密钥验证。

将代码、checkpoint、日志和退出状态写入确认过的持久目录。依赖就绪后先做小规模 GPU 检查，再启动长任务。交互实例可用已有 tmux/nohup；**PaaS 入口命令需以前台进程执行到底**，不要后台化让入口提前结束。

释放前验证必要产物已持久化或取回，核对精确目标后执行授权操作。要求保留实例时照做并说明继续计费。不要用容器内 `shutdown` 代替平台释放。
